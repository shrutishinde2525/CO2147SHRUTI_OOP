# OOP Lab Assignment Practice – C++

This repository contains **C++ programs for Object-Oriented Programming (OOP) Lab assignments and practice**.

The programs cover important OOP concepts such as **classes and objects, constructors, destructors, inheritance, polymorphism, operator overloading, file handling, exception handling, templates, and STL containers**.

## 📚 Assignments

### 1. Online Music Management System

Develop a database for an online music management system containing:

* Song Title
* Song ID
* Artist Name
* Album Name
* Genre
* Duration
* Playlist / Category

Concepts covered:

* Classes and objects
* Default constructor
* Parameterized constructor
* Copy constructor
* Destructor
* Member functions
* Data management

Operations include:

* Add a new song record
* Display song details
* Play a song and maintain play count
* Add/remove songs from playlists
* View song availability and play statistics

---

### 2. Bank Account Management

Design a `BankAccount` class to manage bank account information.

Data members include:

* Account Number
* Account Holder Name
* Account Balance
* Account Type

Concepts covered:

* Static variables
* Static member functions
* `this` pointer
* Friend functions
* Inline functions
* Classes and objects

Operations include:

* Enter account details
* Display account information
* Count total accounts created
* Compare balances of two accounts
* Calculate interest / updated balance

---

### 3. Employee Bio-Data

Create employee bio-data using multiple inheritance.

Classes:

* `PersonalRecord`
* `ProfessionalRecord`
* `AcademicRecord`

Concepts covered:

* Multiple inheritance
* Virtual base class
* Inheritance
* Constructors
* Member functions
* Ambiguity resolution

The program accepts and displays personal, professional, and academic information.

---

### 4. Vehicle Rental System

Design a vehicle rental system for different types of vehicles such as:

* Car
* Bike
* Truck

Concepts covered:

* Abstract classes
* Pure virtual functions
* Runtime polymorphism
* Virtual destructors
* Base and derived classes
* Dynamic memory allocation
* `new` and `delete` operators

The base class is made abstract using a pure virtual function, while a virtual destructor ensures proper cleanup of derived objects.

---

### 5. Complex Number

Implement a `Complex` class to represent complex numbers.

Features:

* Default constructor
* Parameterized constructor
* Addition of complex numbers
* Multiplication of complex numbers
* Input using `>>`
* Output using `<<`

Concepts covered:

* Constructors
* Operator overloading
* Stream operator overloading
* Classes and objects

---

### 6. File Handling

Demonstrate C++ file stream classes to store and retrieve student information.

Student details:

* Name
* Age
* Roll Number

Concepts covered:

* `ofstream`
* `ifstream`
* File creation
* File writing
* File reading
* File closing

The program writes formatted student information to a text file and then reopens the file to read and display the stored information.

---

### 7. User-Defined Exception

Create a user-defined exception program to validate user eligibility.

Conditions:

* Age must be between 18 and 55
* Monthly income must be between ₹50,000 and ₹1,00,000
* City must be Pune, Mumbai, Bangalore, or Chennai
* User must have a 4-wheeler

Concepts covered:

* Exception handling
* User-defined exceptions
* `try`
* `throw`
* `catch`

If any condition is not satisfied, an appropriate exception is thrown.

---

### 8. Function Template – Sorting

Create a function template for sorting arrays in ascending order.

The template should work with:

* Integer arrays
* Floating-point arrays

Concepts covered:

* Function templates
* Generic programming
* Arrays
* Sorting algorithms

The same template function can be used for different data types.

---

### 9. STL Vector – Item Records

Design a program using the STL `vector` container to store and manage item records.

Each item contains:

* Item Code
* Item Name
* Cost
* Quantity

Operations include:

* Input multiple item records
* Sort by item code
* Sort by cost
* Sort by quantity
* Search by item code
* Search by item name
* Display item records

Concepts covered:

* STL `vector`
* Classes
* Sorting
* Searching
* Iterators
* Generic algorithms
